Documentación del API

API de Ventas

Servicio para consultar y registrar ventas por producto, cliente y sucursal.

Base URL: http://localhost:3000/api/v1/ventas

General

  • Formato de respuesta: JSON.
  • Autenticación: no requiere token.
  • Headers recomendados: Content-Type: application/json
  • Fecha recomendada: YYYY-MM-DD

Rutas principales

  • GET /api/v1/ventas/consolidado
  • GET /api/v1/ventas/:id
  • POST /api/v1/ventas

Endpoints

GET/api/v1/ventas/consolidado

Consulta consolidado de ventas por sucursal y año.

Parámetros de consulta

Nombre Tipo Requerido Descripción
sucursal string / number Obligatorio Identificador de la sucursal a consultar.
anio number Obligatorio Año para filtrar el consolidado.

Ejemplo

GET http://localhost:3000/api/v1/ventas/consolidado?sucursal=1&anio=2026

Respuesta exitosa

[
  {
    "id_venta": 1,
    "fecha_venta": "2026-01-15",
    "nombre_cliente": "Ana García",
    "producto": "Laptop",
    "cantidad": 2,
    "monto_venta": 120000
  }
]
GET/api/v1/ventas/:id

Obtiene una venta específica por su identificador.

Parámetros de ruta

Nombre Tipo Requerido Descripción
id number Obligatorio ID de la venta a consultar.

Ejemplo

GET http://localhost:3000/api/v1/ventas/1

Respuesta exitosa

{
  "status": "success",
  "data": {
    "fecha_venta": "15-01-2026",
    "nombre_cliente": "Ana García",
    "ciudad_cliente": "Santiago",
    "producto": "Laptop",
    "cantidad": 2,
    "monto_venta": 120000
  }
}
POST/api/v1/ventas

Registra una nueva venta en el sistema.

Body JSON

Nombre Tipo Requerido Descripción
id_producto number Obligatorio ID del producto vendido.
id_cliente number Obligatorio ID del cliente que realiza la compra.
cantidad number Obligatorio Cantidad vendida del producto.
fecha_venta string Obligatorio Fecha de venta en formato YYYY-MM-DD.

Ejemplo de request

POST http://localhost:3000/api/v1/ventas
Content-Type: application/json

{
  "id_producto": 11,
  "id_cliente": 7,
  "cantidad": 3,
  "fecha_venta": "2026-10-22"
}

Respuesta exitosa

{
  "status": "created",
  "message": "Venta registrada correctamente",
  "datos_registrados": {
    "id_producto": 11,
    "id_cliente": 7,
    "cantidad": 3,
    "fecha_venta": "2026-10-22"
  }
}

Códigos de respuesta

  • 200 Consulta exitosa.
  • 201 Venta creada exitosamente.
  • 400 Parámetros faltantes o inválidos.
  • 404 Recurso no encontrado.
  • 500 Error interno del servidor o de la base de datos.
